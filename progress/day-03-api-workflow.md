# Day 3 — API & AI Workflow

## Objective
Understand how APIs connect an AI workflow to external systems.

## System
AI Lead Qualification System

## Workflow
Lead → AI Analysis → Lead Score → Category → External System → Human Action

## Lead Categories
- Hot
- Warm
- Cold
- Human Review

## API Use Case
When a lead is classified as HOT, the workflow sends the
lead information to a CRM/database/spreadsheet.

## Data Sent
- Name
- Email
- Phone
- Service
- Budget
- Urgency
- Lead Score
- Category
- AI Reason
- Recommended Action

## Human-in-the-loop
Sales team reviews/contact qualified leads.

## Status
API integration not yet implemented.
